# دليل المستخدم – قسم جهات الاتصال

## النسخة الأولى – 30 يوليو 2026

هذا الدليل يشرح قسم **جهات الاتصال** في ChatBerry من منظور المستخدم، ويغطي الشاشة الرئيسية، tooltips، البيانات، الفلاتر، المجموعات، الاستيراد والتصدير، إدارة أكثر من جهة اتصال، وصفحة تفاصيل جهة الاتصال وحالات الاستخدام العملية.

تمت مراجعة الواجهة الحالية ومسارات النظام المرتبطة بها، بما في ذلك نموذج الإضافة والتعديل، شاشة المجموعات، معالج استيراد CSV/XLSX، الفلاتر الجماعية، ومسار حفظ جهات الاتصال. قد تختلف أسماء الأزرار قليلًا إذا تم تغيير لغة الواجهة أو الترجمة.

## 1. ما وظيفة قسم جهات الاتصال؟

قسم جهات الاتصال هو قاعدة العملاء التي يتعامل معها فريقك عبر WhatsApp. من خلاله يمكنك:

- البحث عن عميل بالاسم أو الهاتف أو البريد الإلكتروني أو الدولة.
- تقسيم العملاء إلى مجموعات Groups وتصنيفات Labels.
- معرفة حالة الاشتراك في الرسائل وحالة الحظر ومصدر إنشاء جهة الاتصال.
- إضافة جهة اتصال واحدة أو استيراد آلاف الجهات من ملف.
- إنشاء شريحة دقيقة من العملاء باستخدام الفلاتر.
- تنفيذ تعديل جماعي أو تصدير أو حذف للجهات المحددة.
- فتح المحادثة أو ملف العميل وتعديل بياناته.

### الوصول السريع

| الشاشة | الاستخدام |
|---|---|
| Contacts | القائمة الرئيسية والبحث والفلاتر والتحديد الجماعي |
| Add Contact | إضافة جهة اتصال واحدة يدويًا |
| Contact Profile | عرض وتعديل بيانات جهة اتصال واحدة وفتح المحادثة |
| Groups | إنشاء وإدارة المجموعات واستعراض عدد العملاء داخل كل مجموعة |
| WhatsApp Chat | فتح محادثة العميل مباشرة |

## 2. شرح أعلى الصفحة والإحصاءات

### أزرار الإجراءات الرئيسية

**Import**: يفتح معالج استيراد ملف CSV/XLSX. يجب التأكد من وجود موافقة صحيحة من العملاء على استقبال رسائل WhatsApp قبل استخدامهم في الحملات.

**Export All**: ينزّل نسخة CSV من جميع جهات الاتصال الموجودة في الحساب لاستخدامها في التقارير أو النسخ الاحتياطي. زر التصدير غير متاح لدور Agent في الإصدار الحالي.

**Add Contact**: يفتح نموذج إضافة عميل واحد عندما لا تحتاج إلى رفع ملف كامل.

### بطاقات الإحصاءات

| البطاقة | المعنى | حالة استخدام |
|---|---|---|
| Total Contacts | العدد الكلي للجهات المخزنة في الحساب، سواء ظهرت في النتائج الحالية أم لا | معرفة حجم قاعدة العملاء بالكامل |
| Filtered Contacts | عدد الجهات المطابقة للبحث والفلاتر الحالية | معرفة حجم الشريحة التي يمكن استهدافها الآن |
| Active Filters | عدد شروط التصفية المطبقة حاليًا | التأكد من أن النتائج ليست القائمة الكاملة |

إذا ظهرت عبارة أن الفلاتر مفعلة، فالنتائج المعروضة ليست كامل قاعدة العملاء. استخدم **Reset Filters** للعودة إلى القائمة الكاملة.

## 3. البحث وطريقة عرض البيانات

### البحث السريع

حقل البحث يقبل:

- الاسم الأول أو الأخير أو الاسم الكامل.
- رقم الهاتف، مع أو بدون `+` أو `00` وبعض الفواصل.
- البريد الإلكتروني.
- الدولة المسجلة في عنوان جهة الاتصال.

**حالة استخدام:** اكتب آخر أربعة أو ستة أرقام من الهاتف للعثور بسرعة على عميل اتصل بك، أو اكتب جزءًا من الاسم عند متابعة طلب سابق.

### فلتر الدولة السريع

قائمة **All Countries** تسمح باختيار كود الاتصال الدولي لإظهار العملاء من سوق أو دولة معينة.

**حالة استخدام:** اختر كود دولة معينة لإعداد عرض باللغة المناسبة أو لتحديد توقيت حملة بحسب السوق.

### طرق العرض

| الطريقة | متى تستخدمها؟ |
|---|---|
| Grid | مراجعة بصرية سريعة لكل عميل كبطاقة |
| List | عرض متوسط الكثافة يركز على أهم البيانات |
| Table | المقارنة الدقيقة بين الأعمدة والعمل على التحديد الجماعي |

في بطاقات Grid/List:

- الضغط على البطاقة يحدد جهة الاتصال.
- الضغط على الاسم يفتح الملف الشخصي.
- زر WhatsApp يفتح المحادثة.

في Table يمكنك فتح **Columns** واختيار الأعمدة التي تريدها. الأعمدة الافتراضية هي الاسم والهاتف، ويمكن إظهار البريد، المجموعات، Labels، حالة الاشتراك، المصدر، الدولة، تاريخ الإنشاء، والحقول المخصصة. إعداد الأعمدة يُحفظ محليًا لكل مؤسسة في المتصفح.

### الترقيم Pagination

التنقل بين الصفحات يغيّر الصفحة الحالية فقط ويحافظ على البحث والفلاتر. أما **Select All Results** فيتجاوز حدود الصفحة ويحدد كل النتائج المطابقة للفلاتر.

## 4. بيانات جهة الاتصال ومعنى كل حقل

| الحقل | الشرح | ملاحظة تشغيلية |
|---|---|---|
| First Name | الاسم الأول | مطلوب عند الإضافة اليدوية |
| Last Name | اسم العائلة | اختياري |
| Phone | رقم WhatsApp أو الهاتف | مطلوب، يُنظّم النظام الرقم ويمنع تكراره داخل المؤسسة |
| Email | البريد الإلكتروني | اختياري ويُتحقق من صيغة البريد |
| Subscription Status | هل العميل مشترك في استقبال الرسائل | Subscribed أو Unsubscribed؛ الحملات تعتمد على المشتركين |
| Groups | مجموعات الجمهور مثل VIP أو العملاء الجدد | يمكن أن ينتمي العميل إلى أكثر من مجموعة |
| Labels | تصنيفات تشغيلية مثل Paid أو Pending أو Interested | تساعد الفريق في فهم حالة العميل |
| Source | مصدر إنشاء جهة الاتصال | Platform أو Imported أو WhatsApp أو API |
| Block Status | هل تم حظر العميل | الحظر يمنع الإرسال ويُستخدم لاستبعاد العميل من المتابعة |
| Country | الدولة في بيانات العنوان | تختلف عن كود الهاتف السريع، وتستخدم للتخصيص |
| Created At | تاريخ إنشاء السجل | يساعد في قياس حداثة العميل |
| Custom Attributes | حقول إضافية أنشأتها المؤسسة مثل اللغة أو المرحلة أو رقم الطلب | يمكن عرضها وتعبئتها وتصفية العملاء بها |
| Favorite | تمييز عميل مهم داخل ملفه | مناسب للعملاء ذوي الأولوية |

### أنواع Custom Contact Fields

يمكن إنشاء الحقول المخصصة من **Settings > Contacts**، وتظهر لاحقًا في نموذج الإضافة والتعديل، وفي ملف العميل، وفي أعمدة Table، كما يمكن استخدامها في Mapping أثناء الاستيراد وفي الفلاتر المتقدمة.

| النوع في الإعدادات | أنواع أو خياراته | الاستخدام المناسب |
|---|---|---|
| Input | Text، Number، Email، URL، Date، Time، Date & Time | قيمة قصيرة أو رقم أو رابط أو تاريخ/وقت أو بريد إلكتروني |
| Select box | قائمة خيارات ينشئها المسؤول، ويمكن ترتيبها وإضافة خيارات إليها | قيم محددة مثل Lead، Customer، VIP أو مرحلة الطلب |
| Text area | نص متعدد الأسطر | ملاحظات طويلة أو تفاصيل إضافية عن العميل |
| Checkbox | اختيار نعم/لا أو حالة تفعيل | مثل موافقة خاصة، أولوية، أو وجود مستند |

يمكن جعل أي حقل **Required** من خلال خيار **Is required**. كما يمكن اختيار مكان ظهوره في نموذج وملف جهة الاتصال: **Before address** أو **After address**.

**حالة استخدام:** أنشئ Select box باسم Customer Stage بخيارات New وInterested وWon، ثم استخدمه لتوحيد طريقة تسجيل المرحلة وتصفية العملاء الذين يمرون بمرحلة معينة. استخدم Checkbox عندما تكون القيمة ثنائية، وText area عندما تحتاج وصفًا طويلًا.

### مصادر جهات الاتصال

| المصدر | معنى tooltip | حالة استخدام |
|---|---|---|
| Platform | أُضيفت يدويًا داخل النظام بواسطة الفريق | عميل جديد سجله موظف خدمة العملاء |
| Imported | جاءت من ملف مرفوع | نقل قاعدة عملاء من CRM أو Excel؛ تحقق من الموافقة قبل الحملة |
| WhatsApp | أُنشئت نتيجة تفاعل أو محادثة على WhatsApp | عميل بدأ محادثة من تلقاء نفسه |
| API | أُضيفت تلقائيًا من نظام خارجي أو متجر أو CRM متصل | مزامنة العملاء والطلبات آليًا |

## 5. إضافة وتعديل جهة اتصال يدويًا

### خطوات الإضافة

1. اضغط **Add Contact**.
2. ارفع صورة اختيارية بصيغة JPG أو PNG، وبحجم لا يتجاوز 5 MB.
3. أدخل الاسم الأول ورقم الهاتف وحالة الاشتراك.
4. أضف الاسم الأخير والبريد والمجموعات عند الحاجة.
5. أدخل العنوان: Street، City، State، Zip code، Country.
6. عبّئ الحقول المخصصة المطلوبة أو الاختيارية.
7. اضغط **Save**.

### التحقق عند الحفظ

- الاسم الأول ورقم الهاتف وحالة الاشتراك مطلوبة.
- رقم الهاتف يُحفظ بصيغة موحدة ويجب ألا يكون مكررًا داخل المؤسسة.
- البريد الإلكتروني، إذا تم إدخاله، يجب أن يكون بصيغة صحيحة.
- اختيار أكثر من Group متاح.
- إذا أُرسلت جهة اتصال معدلة بدون أي Group، تُزال مجموعاتها الحالية. لذلك اترك المجموعات المحددة إذا كنت تريد الاحتفاظ بها.
- تعديل البيانات المخصصة يدمج القيم الجديدة مع القيم المحفوظة بدل حذف جميع البيانات الأخرى.

**حالة استخدام:** عند تسجيل عميل أثناء محادثة، أضف اسمه وهاتفه، اختر Subscribed فقط إذا كانت الموافقة متوفرة، وضعه في Group مناسب مثل New Customer، ثم افتح Chat للمتابعة.

## 6. الفلاتر المتقدمة وإنشاء شريحة عملاء

اضغط **Advanced Filters** لتحديد شريحة دقيقة، ثم اضغط **Apply**. تستخدم الفلاتر التالية:

### Group و Label

- اختيار Group أو أكثر يعرض العملاء المنتمين إلى هذه المجموعات.
- **No Group** يعرض العملاء غير المنتمين إلى أي مجموعة.
- اختيار Label أو أكثر يعرض العملاء الذين يحملون هذه التصنيفات.
- **No Label** يعرض العملاء الذين لا يحملون أي Label.

للحصول على نتيجة واضحة، استخدم No Group أو No Label كبحث مستقل عند الحاجة؛ الجمع بينه وبين عناصر مسماة قد ينتج شروطًا متقاطعة جدًا.

### Status

- **Subscribed**: العملاء المسموح باستهدافهم في الحملات وفق حالة الاشتراك.
- **Unsubscribed**: العملاء الذين أوقفوا الاشتراك؛ لا تُرسل لهم حملات.

حالة الاشتراك تُستخدم أيضًا في إنشاء الحملات وبعض تكاملات المتجر، لذلك لا تغيّرها لتجاوز رغبة العميل.

### Contact Source

يمكن تصفية العملاء حسب Platform أو Imported أو WhatsApp أو API. هذا مفيد لفصل قاعدة العملاء المستوردة عن العملاء الذين بدأوا محادثة فعلية.

### Block Status

- **Blocked**: العملاء المحظورون.
- **Not blocked**: العملاء غير المحظورين.

الحظر يمنع إرسال الرسائل المباشرة والحملات وطلبات API، كما يتعامل النظام مع الرسائل الواردة للعميل المحظور على أنها غير قابلة للمعالجة. استخدم Block عند وجود سبب تشغيلي أو طلب واضح، ثم استخدم Unblock عند زوال السبب.

### التاريخ والحقول المخصصة

- **Created From**: يعرض العملاء الذين أُضيفوا في أو بعد تاريخ معين.
- **Created To**: يعرض العملاء الذين أُضيفوا في أو قبل تاريخ معين.
- **Custom Attribute** + **Contains value**: يبحث عن جزء من قيمة حقل مخصص مثل `stage = lead` أو `language = Arabic`.

**حالة استخدام كاملة:** أنشئ شريحة من Group “Interested”، ثم Subscription = Subscribed، وCountry code = دولة معينة، وCreated From = بداية الشهر. ستكون النتيجة مناسبة لحملة مخصصة مع تقليل خطر إرسال رسالة إلى عميل غير مشترك.

## 7. التحديد والإجراءات الجماعية

### أنواع التحديد

- مربع تحديد الصفحة يحدد أو يلغي تحديد العملاء الظاهرين في الصفحة الحالية فقط.
- **Select All Results** يحدد كل العملاء المطابقين للبحث والفلاتر عبر جميع الصفحات.
- بعد تحديد الكل يمكن إلغاء تحديد جهات فردية، وتُعامل هذه الجهات كاستثناءات.
- زر **Clear Selection** يلغي التحديد.

يُحفظ التحديد مؤقتًا في المتصفح لكل مؤسسة، لذلك راجع شريط التحديد قبل تنفيذ إجراء حساس، خصوصًا بعد العودة إلى الصفحة أو تغيير الفلاتر.

### شريط الإجراءات الجماعية

بعد التحديد تظهر الإجراءات التالية:

| الإجراء | النتيجة |
|---|---|
| Add Labels | إضافة Labels إلى جميع الجهات المحددة دون إزالة التصنيفات الأخرى |
| Remove Labels | إزالة Labels المختارة |
| Add Group | إضافة الجهات إلى Group دون إزالة مجموعاتها الأخرى |
| Remove Group | إزالة الجهات من Group المحدد |
| Change Subscription | ضبط الحالة إلى Subscribed أو Unsubscribed جماعيًا |
| Export Selected | تنزيل الجهات المحددة فقط؛ غير متاح لـ Agent |
| Delete | حذف الجهات المحددة حذفًا منطقيًا؛ غير متاح زرّه لـ Agent |
| Clear Selection | إلغاء التحديد الحالي |

عند استخدام Select All Results، يُطبق الإجراء على كامل النتائج المطابقة للفلاتر، وليس على الصفوف الظاهرة فقط. راجع Filtered Contacts والفلاتر النشطة قبل الحذف أو تغيير الاشتراك.

**حالة استخدام:** بعد استيراد العملاء، استخدم Filtered Contacts لاختيار العملاء من مصدر Imported، ثم Add Group إلى “Imported Leads”، ثم Add Label إلى “Needs Review” بدل تعديلهم واحدًا واحدًا.

## 8. استيراد جهات الاتصال من ملف

يفتح زر **Import** معالجًا من خمس مراحل. يقبل مسار الاستيراد الحالي CSV وXLSX، والحد الأقصى للرفع في المعالج هو 50 MB.

### قبل رفع الملف

يفضل أن يحتوي الملف على الأعمدة التالية:

`first_name`, `last_name`, `phone`, `email`, `group_name`, `street`, `city`, `state`, `zip`, `country`

ويمكن إضافة أعمدة للـ Custom Attributes الموجودة في المؤسسة. يجب حفظ الهاتف بصيغة دولية قدر الإمكان، وتجنب الخلايا الفارغة أو الصيغ التي تحول الهاتف إلى رقم عشري.

### المرحلة 1 – Upload

اختر الملف. ينشئ النظام Import Batch ويقرأ العناوين والصفوف للمعاينة. إذا كان الملف كبيرًا جدًا، ينتقل النظام مباشرة إلى Background Import.

### المرحلة 2 – Mapping

اربط كل حقل في النظام بالعمود المناسب في الملف. الهاتف مطلوب. الحقول الإضافية تشمل الاسم الأخير، البريد، اسم Group، الدولة والعنوان والحقول المخصصة.

**حالة استخدام:** إذا كان عمود الهاتف في ملفك اسمه `Mobile Number`، اختره في Phone. لا تعتمد على تشابه الاسم فقط؛ راجع العمود الذي يحتوي الأرقام فعليًا.

### المرحلة 3 – Review Invalid Numbers

يفحص النظام الأرقام ويحوّلها إلى صيغة موحدة.

- إذا كان الرقم محليًا ولا يحتوي كود دولة، اختر Default Country Code ثم اضغط **Check numbers**.
- تظهر إحصاءات Total وValid وInvalid وRemoved.
- تظهر رسالة إذا كانت أرقام موجودة مسبقًا داخل Groups.
- الصفوف غير الصالحة لا تُستورد حتى تُصلح أو تُزال.
- يمكن تعديل الصف وبياناته ثم إعادة الفحص.
- يمكن تنزيل تقرير CSV بالأرقام غير الصالحة. قد تعرض الشاشة معاينة محدودة، بينما التقرير ينزّل جميع الصفوف غير الصالحة.

### المرحلة 4 – Audience / Group Assignment

اختر طريقة ربط العملاء بالمجموعات:

1. **Add all contacts to selected audience**: اختر Groups موجودة أو اكتب اسم Group جديدة. ستوضع كل الصفوف الصالحة في هذه المجموعات.
2. **Split contacts across generated audience**: حدد عدد العملاء في كل Group وبادئة الاسم. مثال: `batch_1`, `batch_2`، مع توزيع العملاء بالتتابع.
3. **Use audiences from file**: فعّلها بعد ربط عمود `group_name`. يقرأ النظام اسم Group من كل صف، ويعيد استخدام الموجود أو ينشئ غير الموجود تلقائيًا. يمكن كتابة أكثر من Group في الخلية وفصل الأسماء بالرمز `|`.

**حالة استخدام:** عند رفع قائمة من حملة إعلانية، استخدم Group من الملف إذا كان كل صف يحمل مصدرًا مختلفًا. وعند رفع قائمة كبيرة لإرسالها على دفعات، استخدم Split.

### المرحلة 5 – Import Report

اضغط **Execute Import** بعد التأكد من الصفوف الصالحة وتعيين Groups. يعرض التقرير:

- Success وFailed.
- Created للجهات الجديدة.
- Updated للجهات الموجودة التي تم تحديثها.
- Duplicates للصفوف المكررة.
- رابط تنزيل Failure Report CSV.

### التكرار والدمج أثناء الاستيراد

- الهاتف هو مفتاح المطابقة الأساسي بعد التطبيع.
- الصفوف المكررة داخل الملف تُجمع في جهة اتصال واحدة بدل إنشاء سجلات مكررة.
- إذا كان الهاتف موجودًا في المؤسسة، تُحدّث بياناته بدل إنشاء جهة جديدة.
- تُدمج Custom Attributes الجديدة مع البيانات الموجودة.
- تُضاف Groups الجديدة دون إزالة المجموعات الموجودة.
- الصف الجديد الناتج من الاستيراد يحمل Source = Imported.

### الاستيراد في الخلفية للملفات الكبيرة

إذا تجاوز الملف 10,000 صف، يستخدم النظام Background Import. في هذه الحالة يجب أن يحتوي الملف على Phone وGroup Name، ويبدأ التنفيذ تلقائيًا في الخلفية مع شريط تقدم ومراحل مثل قراءة الملف، حفظ الصفوف غير الصالحة، حفظ جهات الاتصال، ربط المجموعات وتحديث أعدادها.

تعرض الشاشة Total، Valid rows، Invalid، Duplicates، Imported contacts، Created وUpdated. عند انتهاء العملية يمكن تنزيل تقرير الأرقام غير الصالحة وتقرير الفشل.

## 9. إدارة Groups / Audiences

المجموعات هي شرائح عملاء تستخدمها قبل الحملات أو المتابعة.

### من نافذة Groups داخل Contacts

- إنشاء Group جديدة.
- البحث في أسماء Groups.
- اختيار Group لتطبيق فلتر على العملاء.
- رؤية عدد العملاء داخل كل Group.
- تحديد Groups للحذف أو حذف Group واحدة.

حذف Group يفصل العملاء عنها ولا يحذف سجلات العملاء نفسها، لكن قد يؤثر على الحملات أو التقارير التي تعتمد على هذه المجموعة؛ تأكد قبل الحذف.

### من صفحة Groups المستقلة

- عدد Groups المتاحة في الحساب.
- إضافة Group جديدة مثل VIP أو Pending Payment.
- Bulk Upload لرفع أسماء Groups متعددة بدل إدخالها يدويًا.
- اختيار Group لعرض تفاصيلها وعدد العملاء بداخلها.
- البحث والتنقل بين الصفحات.
- تصدير Groups للمراجعة أو النسخ الاحتياطي في المسار المدعوم.

**حالة استخدام:** أنشئ “VIP Customers” و“Pending Payment” و“Interested Leads”، ثم اربط كل جهة اتصال بالمجموعة المناسبة لتجنب إرسال نفس الرسالة العامة إلى الجميع.

### إنشاء جمهور من Label

إذا كان لديك Label يضم مجموعة محددة من العملاء، يمكنك تحويله إلى جمهور Group من خلال:

1. انتقل إلى **Settings > Labels**.
2. بجانب الـ Label المطلوب اضغط زر **Create Group from Label**.
3. أدخل **Group Name** الجديد.
4. اضغط **Create Group**.

ينشئ النظام Group جديدة ويضيف إليها جميع جهات الاتصال المرتبطة بذلك الـ Label، ثم يعيد حساب عدد أعضاء المجموعة. بهذه الطريقة يمكن استخدام نفس الشريحة كـ Group في الفلاتر والاستيراد والحملات.

**حالة استخدام:** إذا كان Label باسم “Pending Payment”، أنشئ منه Group باسم “Payment Follow-up Audience” لتحديد العملاء بسهولة في Contacts واستخدامهم في متابعة مخصصة.

ملاحظة: عند تكرار العملية باسم Group موجود مسبقًا، قد ينشئ النظام Group جديدة بالاسم نفسه؛ استخدم اسمًا واضحًا وتحقق من قائمة Groups قبل الإنشاء.

## 10. صفحة تفاصيل جهة الاتصال

اضغط على اسم العميل لفتح ملفه. تظهر فيه:

- الصورة والاسم ورقم الهاتف.
- Edit لتعديل السجل.
- Chats لفتح محادثات العميل.
- Favorite لتثبيت أهمية العميل.
- Block أو Unblock.
- Subscription Status وBlocked Status.
- البريد الإلكتروني، Groups، Labels.
- الحقول المخصصة.
- العنوان الكامل.

**حالة استخدام:** قبل الرد على عميل مهم، افتح ملفه لمراجعة Labels وSubscription والعنوان والحقول المخصصة، ثم اضغط Chats لفتح المحادثة مع الاحتفاظ بسياق فريق العمل.

## 11. قواعد تشغيل موصى بها

- لا تستورد أرقامًا لم تحصل على موافقة أصحابها على رسائل WhatsApp.
- استخدم Subscribed وUnsubscribed كحالة حقيقية للموافقة، وليس كوسيلة لتجاوزها.
- استخدم Block للمنع التشغيلي الصريح، ولا تعتمد عليه بدل إلغاء الاشتراك.
- قبل أي إجراء جماعي، راجع عدد Filtered Contacts وشريط الفلاتر.
- استخدم Select All Results فقط عندما تكون متأكدًا من أن الفلتر يمثل الجمهور المطلوب.
- استورد ملفًا صغيرًا تجريبيًا أولًا للتحقق من mapping وتنسيق الهاتف والمجموعات.
- احتفظ بنسخة Export قبل حذف مجموعات أو جهات اتصال كثيرة.
- اجعل أسماء Groups وLabels واضحة وثابتة حتى يفهمها جميع أعضاء الفريق.
- لا تضع بيانات حساسة في Custom Attributes إلا إذا كانت هناك حاجة تشغيلية وصلاحيات مناسبة.

## 12. حالات استخدام عملية مختصرة

### استيراد عملاء جدد

جهز CSV يحوي الاسم والهاتف والبريد و`group_name`، ارفعه، اربط Phone، افحص الأرقام، اختر Use audiences from file، ثم نفذ الاستيراد وراجع Created وInvalid.

### حملة لعملاء مشتركين في دولة معينة

اختر Country Dial Code، ثم Subscription = Subscribed، ثم Group أو Label المناسبة. راجع Filtered Contacts، حدد كل النتائج، ثم صدّرها أو استخدمها في الإجراء التالي.

### تنظيف بيانات ناقصة

استخدم No Group أو No Label، راجع النتائج في Table، أضف Group أو Label جماعيًا، ثم استخدم Created From/To لمراجعة الدفعة الزمنية المعنية.

### إيقاف التواصل مع عميل

افتح ملفه، غيّر Subscription إلى Unsubscribed إذا طلب إيقاف الرسائل، واستخدم Block إذا كان هناك سبب تشغيلي لمنع الإرسال والتعامل مع الرسائل الواردة.

### تقسيم ملف كبير إلى دفعات

ارفع ملفًا يحتوي Phone وGroup Name، وانتظر Background Import. استخدم Split في الملفات التي تحتاج مجموعات متتابعة، أو Use audiences from file إذا كان لكل صف تصنيف مستقل.
